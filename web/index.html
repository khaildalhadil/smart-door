القفل الذكي

الصفحة جاهزة، وباقي ربطها بقاعدة البيانات.

  1. أنشئ مشروعًا مجانيًا في supabase.com ونفّذ الملف supabase/schema.sql من SQL Editor.
  2. ضع Project URL والمفتاح publishable في الملف web/config.js.
  3. أنشئ حسابك من Authentication → Users → Add user ثم حدّث هذه الصفحة.

سجّل الدخول لعرض بيانات الباب.
